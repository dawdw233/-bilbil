# 刷B站 · AstrBot 插件

按兴趣选视频，按人设聊内容。

让机器人按关键词逛 B站，阅读字幕、筛选值得看的视频，再整理成日报。你可以设置它什么时候刷、喜欢什么、怎样说话，以及是否参与评论和回复；也可以直接在聊天里发送视频链接，让它查字幕、评论和楼中楼。

## 功能一览

| 功能 | 说明 | 面板入口 |
|---|---|---|
| 搜索与选片 | 按关键词搜索并去重，结合字幕判断内容；无字幕时尝试使用简介与热评 | 刷视频 |
| 作息安排 | 自定义时间窗口、醒来次数、最小间隔和不看概率，在窗口内随机安排 | 作息 |
| 日报与历史 | 按日期查看日报，查看每轮运行结果和看过的视频 | 刷视频 |
| 日报投递 | 按需推送到 QQ 或发送 B站私信 | 投递 |
| 自动评论 | 结合评论口味和开口积极性决定是否评论，支持每日上限、评论间隔和指定昵称 @ | 评论 |
| 人设与风格 | 实时跟随 AstrBot 当前默认人设卡，或使用自己填写的说话风格 | 评论 → 说话风格 |
| 回复互动 | 检测别人对它的回复及使用者本人的 @，支持关闭、草稿待审和自动回复 | 回复 |
| 视频投稿 | 从插件素材目录选择视频，填写投稿信息后提交 | 投稿 |
| 聊天查询 | 支持视频链接、BV 号与 b23.tv 短链，查询字幕、评论和楼中楼 | QQ 聊天 |

## 开始使用

1. 在 AstrBot WebUI 中打开「插件 → 刷B站 → 面板」，扫码登录 B站。
2. 在「刷视频 → 设置」填写关键词，选择模型；模型留空时使用 AstrBot 当前默认模型。
3. 点击「跑一轮」，查看筛选结果、日报和运行记录。
4. 按需要配置「作息」和「投递」。评论、回复均在各自页面单独设置。

每个设置区块修改后点击对应的保存按钮。

## 面板外观与插画

面板采用固定分组导航、轻量工具栏和冰蓝书房欢迎卡。导航按「阅读、写作、生活」组织现有功能，欢迎卡内置蓝色系日系人物插画，以渐变留白衔接宋体标题。

工具栏的页面模式默认为「随时间」：按北京时间每天 19:00 至次日 07:00 自动使用夜晚配色，其余时间为浅色，页面打开时每 30 秒检查一次，重新切回页面也会更新。可手动选择浅色或夜晚模式，选择由插件独立保存，换浏览器也保留。夜晚使用低饱和深蓝灰卡片，柔和压低插画亮度，并保留玻璃、锐化与自定义图片设置。

欢迎卡下方展示今日时间轴、自动唤醒圆环进度和统计卡。时间轴展示今日最近的运行记录及下一次唤醒；暂无记录时显示已配置的作息窗口。进度按自动唤醒次数计算，按计划跳过也计入进度，手动运行单独记在运行记录中。统计卡展示今日精选、今日自动评论、待审回复及累计去重记录，均来自插件实际记录；浏览面板不会触发模型或 B站互动。

点击工具栏的「外观与插画」，可上传、替换或移除欢迎卡插画，并实时预览水平与垂直位置、缩放、裁剪方式、不透明度和渐变遮罩的颜色与强度。

选择「完整显示」时插画自动靠右，将因宽高比产生的水平留白放在文字一侧；100% 缩放下保留整张图片。水平位置暂时停用，但保留原数值，切回「铺满画面」后恢复。首页和设置预览使用相同的对齐方式。

插画玻璃质感支持独立开关和 0～100% 强度调节，默认开启、强度 50%。强度越高，反光与柔光越明显，0% 无玻璃效果；关闭后保留上次强度。调整同步显示在欢迎卡和设置预览中，保存后刷新仍保留，取消会恢复原设置。

插画锐化可独立调节 0～100%，默认 0%，通过增强相邻像素的边缘对比改善轮廓细节，保留平坦区域亮度与透明通道。支持实时预览与保存；关闭玻璃效果后仍可锐化，恢复默认时锐化归零并保留图片。

工具栏的「流星设置」是独立面板，入口仅在夜晚模式显示，切回浅色时自动隐藏并收起已打开的面板，保留已保存的流星参数。提供开关、数量 0～256 道、亮度 0～100% 和划过速度 0.25×～2.00×。默认开启 128 道、亮度 72%、速度 1.00×，面板内可实时预览。小屏幕自动减少显示数量，系统开启减少动态效果时暂停流星。点击「保存流星设置」后刷新或换浏览器仍保留，取消会恢复已保存的效果，关闭开关后保留参数。「恢复流星默认」只重置流星，不改动插画图片、位置、玻璃、锐化或遮罩设置。原版本保存的流星参数会自动沿用，后续独立保存到 `meteor.json`。

点击左侧头像可单独选择、替换头像，图片居中裁剪为圆形，保存后刷新或换浏览器仍保留。自选头像不会被欢迎卡插画覆盖；「恢复默认」并保存后，头像重新跟随页首插画。头像与插画分开存储，取消预览不会改动已保存的头像。

头像设置支持常用边框色块和自定义选色，高光、渐变与阴影跟随颜色实时预览，点击「保存头像」后保留。取消会还原已保存颜色；恢复默认会同时还原默认头像和薄荷绿边框。升级时保留已有自选头像。

点击头像旁的书房名称或小铅笔，可修改为 1～24 个字符的名称。保存后侧栏、欢迎卡标题和顶部路径同步更新，刷新或换浏览器仍保留；取消不会改动原名，也可恢复默认的「一隅书房」。

支持 PNG、JPG、WebP 图片，原图最大 20 MB，处理后最大 3 MB。点击「保存外观」后，插画和外观参数由插件保存，刷新后恢复；取消或关闭设置会还原未保存的预览。移除插画后使用同色系渐变背景。「恢复默认」只重置插画外观参数，保留当前插画和独立的流星设置；已移除图片时也保持无插画状态，保存后生效。已有自定义插画在升级时保留。

外观通过插件接口保存在插件数据目录的 `appearance.json`，兼容 AstrBot 的隔离面板，不依赖浏览器本地存储；不同浏览器和设备可读取同一份已保存外观。

## 评论口味、积极性与说话风格

这三项分别控制不同的事情：

- **评论口味**：勾选「按文本框里的口味筛选」时，按喜欢与不喜欢的内容挑选；取消勾选后不读取口味文字，也不按开口积极性挑选，为本轮选中的视频逐条生成评论。关闭期间保留原文字，重新勾选后可继续使用；旧配置默认开启。
- **开口积极性**：保守、正常、积极，启用口味筛选时决定它多容易开口；关闭口味时不参与挑选。
- **说话风格**：评论和回复使用的性格、语气与表达习惯。

评论口味开关在本区块保存后生效。逐条评论仍需开启自动评论，遵守次数上限、间隔、已评去重与内容检查；素材不足或生成失败时不会强行发送。关闭口味后，回复也不读取口味文字，但仍按回复规则判断是否回应。

在「评论 → 说话风格」中：

- **勾选绑定 AstrBot 当前默认人设卡**：每次生成评论或回复时重新读取人设。切换默认人设或修改卡片后，下一次生成自动跟随，无需重启或重新保存插件配置。
- **取消绑定**：使用下方文本框的内容；留空使用内置风格。
- 绑定时文本框暂停编辑，已经输入的内容会保留，取消绑定后可继续使用。

绑定跟随的是 AstrBot 当前默认人设卡。更改绑定开关后，需要点击「保存」。

## 回复与草稿

在「回复」中选择处理方式：

- **关闭**：不检测新的回复。
- **先写草稿**：生成后放入待审队列，由管理员确认发送或丢弃。
- **自动回复**：模型判断需要回复时自动发送，并遵守配置的每日上限和间隔。

直接在评论区 @ 它的消息，仅接收使用者本人发来的 @。聊天中手动要求回复某条评论时，回复会先进入待审队列；顶层新评论由自动评论流程生成。

## 聊天里怎么用

发送视频链接、BV 号或 b23.tv 短链后，说明想了解什么：

| 你可以这样说 | 它会做什么 |
|---|---|
| 搜一下整活视频 | 搜索 B站视频 |
| 这个视频讲了什么 | 读取视频字幕 |
| 评论区都在聊什么 | 读取评论，并标出账号自己发过的评论 |
| 这条评论下面在聊什么 | 展开楼中楼 |
| 有人回复我或者 @ 我吗 | 查看收到的回复及使用者本人的 @ |
| 看看有哪些待发的回复 | 列出待审草稿，供管理员确认 |
| 帮我回这条评论：…… | 把回复加入待审队列 |
| 发这条草稿／丢弃这条草稿 | 根据草稿 ID 发送或丢弃，仅管理员可操作 |

聊天工具由模型按请求选择；没有额外的 `/bili` 命令。

## 投稿

先把视频放入面板显示的素材目录，再到「投稿」选择文件，填写标题、分区等信息并提交。面板可查看投稿状态和结果。

## 开发与维护

从 [dsh-bili-scroll 2.0](https://github.com/c1overzz/dsh-bili-scroll)（MIT）移植，B站工具层基于上游的 bilibili-mcp。

- `main.py`：插件入口、面板接口和聊天工具。
- `duty.py`：搜索、去重、读取内容、筛选、评论与日报流程。
- `rhythm.py`：时间窗口与随机唤醒计划。
- `reply.py`：回复处理和待审草稿。
- `prompts/`：视频判断、评论、回复提示词。
- `pages/panel/index.html`：插件面板。

维护页面时需保留 bridge SDK 引用和唯一的 HTML body 结束标签；不要在脚本或注释中重复写入该结束标签，以免破坏页面注入。

界面检查：运行 `node --test tests/panel-appearance.test.mjs tests/panel-study.test.mjs`；在安装了 AstrBot 依赖的环境中运行 `python -m unittest discover -s tests -p "test_*.py"`。检查均不调用真实模型，也不会向 B站发送内容。
